# Migration Database 2

Migration di folder ini belum dijalankan oleh Laravel. Folder ini menyimpan migration
untuk Database 2 (`transaksi`) sampai struktur Database 1 untuk akun dan kebutuhan
Laravel selesai diverifikasi.

Untuk mengaktifkannya nanti, pindahkan file PHP dari folder ini kembali ke
`database/migrations`, kemudian jalankan migration dengan konfigurasi Database 2
yang sesuai.
